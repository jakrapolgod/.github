# .github

ไฟล์ตั้งค่าเริ่มต้นที่ใช้ร่วมกันทุก repository ของบัญชีนี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `.github/FUNDING.yml` | ปุ่ม **Sponsor** ที่หน้า repo ชี้ไปยังหน้าสนับสนุนผ่านพร้อมเพย์ |
| `CLAUDE.md` | กติกาให้ Claude เขียน code อัลกอริทึมตามหลักวิชา Analysis and Design of Algorithms |
| `.claude/skills/algorithm-analysis-design/` | skill ของวิชา: ขั้นตอนบังคับ 7 ขั้น และตัวอย่าง `template.py` (Coin Change: greedy ที่ดูถูกแต่ผิด กับ DP ที่พิสูจน์และทดสอบแล้ว) |

repo ที่ต้องการตั้งค่าต่างจากนี้ ให้สร้าง `.github/FUNDING.yml` ของตัวเอง
